* Topdown turn-based tactical shell shooter-launcher
* You all have been sent to aid recapturing the island from the enemy
* You lead mortar and artillery teams to coordinate precision strikes
* Each position and point differ by devices, targets and placements, think tactically!

## Description

* Drumstalotājs (*The Crumbler* in Latvian, for player is the one) is a minimalistic wargame with a focus on the artillery and mortar strikes. The player's aim is to retake in-game's Rocky Island and player commands an unit from mortar teams to artillery batteries in each level on the island with aim to destroy targets to support the player's army's efforts to retake the island.

* Project made as a diploma work for Liepāja State Technical University

## How to Play

* Place devices in assigned fields
* Adjust their traverse, elevation and firing times at the target
* After firing, correct device configurations until all targets are destroyed or time has run out

## Running

Minimum required hardware specifications to run the game:

* 1GB RAM
* 1GHz CPU
* 640x480 Resolution
* 200MB Hard drive space
* OpenGL 3.3 or Direct3D 11

Required software minimum versions to run the game:

* .NET Framework 10
* Windows platform: Windows 10 64-bit
* Linux platform: glibc 2.28

## Building

Required software to access, edit and build the project:

* .NET Framework 10
* Godot 4.6

This is done by opening the project repository in Godot editor, selecting "Export" and choosing a preexisting platform or creating a new exportable platform.
